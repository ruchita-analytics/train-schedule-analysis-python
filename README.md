# Train Schedule Analysis and Interactive Route Enquiry System Using Python

## Internship Project

**Organization:** Sysslan IT Solutions  
**Domain:** Data Analysis  
**Project:** Train Schedule Analysis and Interactive Route Enquiry System Using Python

---

## 📌 Project Overview

This project focuses on comprehensive analysis of train schedule data using Python.

The project covers data exploration, data cleaning, preprocessing, journey duration analysis, station traffic analysis, data visualization, advanced analysis, and development of an interactive train enquiry system.

The main objective is to derive meaningful insights from train schedule data and provide route-based train information.

---

## 🎯 Project Objectives

- Understand the structure and quality of the train dataset
- Perform data cleaning and preprocessing
- Analyze train routes and station information
- Calculate journey duration for each train
- Classify routes based on journey duration
- Analyze station-wise train frequency
- Identify high-traffic stations
- Create meaningful data visualizations
- Perform advanced analysis using pivot tables and cross-tabulations
- Develop an interactive train enquiry system

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Project Levels and Tasks

### Level 1 – Basic Data Review

- Reviewed dataset structure, size, and attributes
- Listed trains with starting and ending stations
- Calculated number of stops per train
- Identified trains with maximum and minimum stops

**Skills:** Data Exploration, Pandas, Data Summarization

---

### Level 2 – Simple Data Processing

- Standardized arrival and departure time fields
- Calculated total journey duration for each train
- Classified routes as Short, Medium, or Long
- Generated station-wise train frequency counts

**Skills:** Data Preprocessing, Datetime Operations, Classification, Pandas Grouping

---

### Level 3 – Data Quality Checks

- Handled missing schedule values
- Removed duplicate train records
- Verified station order for each route
- Saved the verified and cleaned dataset

**Skills:** Data Cleaning, Missing Value Handling, Duplicate Removal, Data Validation

---

### Level 4 – Basic Analysis and Visualization

- Compared average journey durations across route types
- Identified high-traffic stations
- Created visualizations for journey duration and station traffic
- Summarized important observations and insights

**Skills:** Exploratory Data Analysis (EDA), Matplotlib, Seaborn, Data Visualization

---

### Level 5 – Advanced Analysis and Visualization

- Created pivot tables for station-wise train distribution
- Performed cross-tabulation analysis between stations and routes
- Created comparative charts from pivot and cross-tab results
- Summarized advanced analytical insights

**Skills:** Pivot Tables, Cross-Tab Analysis, Advanced Visualization, Comparative Analytics

---

### Level 6 – Final Capstone System

Developed an interactive route-based train enquiry system.

The system provides:

- Direct trains between source and destination
- Estimated journey duration
- Route-based train information

**Skills:** Python Programming, User Input Handling, Data Lookup, Application Development
